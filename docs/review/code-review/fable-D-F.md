## Zusatzfrage Belegzwang: Kann eine Aussage ohne passende Evidence durchrutschen?

Ja, auf mehreren Wegen (belegt durch Codelektüre an HEAD):
1. **Fremde Evidence-ID:** wird abgefangen (verifier.py:45, Test g2). Eine ID aus einem anderen Job oder eine unbekannte ID wird verworfen; eine ID aus einer anderen Aufgabe desselben Jobs ist zulässig, was gewollt ist.
2. **Teilstring:** rutscht durch. Jeder Teilstring ab 4 Zeichen bestätigt jede Aussage (Fund "hoch", verifier.py:49-52). Der schärfste Fall ist das Argument-Echo (Fund "krit"): Das Modell kann den gewünschten Wert selbst in die Evidence schreiben.
3. **Zitat-Normalisierung:** rutscht teilweise durch. Zeilenübergreifende Zitate gelten als zusammenhängend (verifier.py:20). Unicode wird nicht normalisiert, das schlägt aber sicher fehl (Zitat wird verworfen).
4. **Antwort aus Hypothese:** rutscht durch. Die Antwort braucht nur irgendein bestätigtes Finding derselben Antwort; Freitextwerte werden nicht geprüft (runner.py:252-257, engine.py:371-376, verifier.py:70).
5. **Bericht:** IOCs stammen aus dem Aussagetext, nicht aus Zitaten (builder.py:142); `open`-Findings des Guards haben keine Evidence (engine.py:286); UNRESOLVED-Text erscheint ungeprüft in R5.
